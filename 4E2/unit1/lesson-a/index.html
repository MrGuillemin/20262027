Exercise 1 — There is / There are

Choisis la réponse qui complète correctement la phrase.

  4. _____ public transport at night. ❌there is · there are · there isn't any · there aren't any
  5. _____ some greenery near the lake.there is · there are · there isn't any · there aren't any
  6. _____ many modern buildings.there is · there are · there isn't any · there aren't any
  7. _____ a sports centre near my school.there is · there are · there isn't any · there aren't any
  8. _____ three parks in the city centre.there is · there are · there isn't any · there aren't any
